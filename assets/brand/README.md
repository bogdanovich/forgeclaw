# MintClaw Brand Assets

This directory contains display-optimized PNGs for repository pages and the
original source exports supplied for the MintClaw project.

## Display Assets

| File | Dimensions | Intended use |
| --- | ---: | --- |
| `mintclaw-wordmark-1600.png` | 1600 × 640 | README hero and wide layouts |
| `mintclaw-logo-768.png` | 768 × 768 | README sections and general logo use |
| `mintclaw-telegram-avatar-512.png` | 512 × 512 | Telegram and other square avatar previews |

The optimized files reduce repository-page transfer and rendering cost. Their
warm background is part of the supplied artwork; the PNGs are not transparent.

## Original Exports

Exact, unmodified copies are retained under `originals/`:

| File | Dimensions |
| --- | ---: |
| `originals/mintclaw-logo-4096.png` | 4096 × 4096 |
| `originals/mintclaw-logo-wordmark-4096.png` | 4096 × 1638 |
| `originals/mintclaw-telegram-avatar-2048.png` | 2048 × 2048 |

Use the optimized files in normal documentation. Keep the original exports as
the source for future crops, sizes, or formats rather than repeatedly resizing
an already optimized derivative.
